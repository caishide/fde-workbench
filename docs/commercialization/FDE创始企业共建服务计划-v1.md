# FDE 创始企业共建服务计划 v1.0

**定位**：本计划是「用真实付费服务换出真实企业案例与共建」的落地文件。**它不是**「服务费赠送原始股」的合伙计划——原始设想经 2026-11-26 九轮澄清后，股权型权益已降级为后置、待律师审定的可选层（见 §3 关键事实与 §7 未决事项）。

**授权状态**：本文件记录 2026-11-26 交互式拍板的全部结论（九轮，全部落推荐项）。签字／律师审定／业务财务确认前，本计划不构成任何对外承诺。

**与既有文件的关系**：本计划不改写《官网诊断获客与上门访谈详细设计 v1.0》《标准业务体系设计方案 v1.0》《商业计划书 v4.1 投资人版》的既有口径；与它们冲突时，以既有文件与本计划的「不越界声明」为准（见 §6）。

---

## 1. 为什么做这件事

招商与融资的前置条件是「有跑通的真实企业案例、有沉淀的基础 FDE 产品」。当前两者都缺：

| 缺口 | 现状证据 |
|---|---|
| 真实付费案例 | 仓内无真实到账记录。somwyn 的 ¥3,300 里程碑为记账模式，无到账凭证 |
| 首单签约 | DIFF-09 分账口径签署未完成，签约与收费各自需单独授权 |
| 招商条件 | 正式区域合作商售卖闸挂在特许经营四项合规条件（备案／提前 30 日披露／冷静期／两店一年），规则文件自述「是否被认定为特许经营须律师出具意见」 |
| 体系可复制性 | 未验证「同一个标准件能否重复做出来」 |

因此本计划的定位是：**先用直营服务把案例与单位经济性跑出来，再谈招商与融资**。它绕开的是「先有规模后有案例」的循环，不是绕开合规闸。

## 2. 两阶段路径

### 阶段一（进行中，口径不改）：官网只读试点

- 现行范围不变：只测「官网由头能不能换来一次回应」，零派单、零上门、零席位、不做平台免费诊断、不涉及成交与分账。
- 触达执行人＝蔡工本人；AI 只读采集（首页快扫 ≤8 家＋深审 ≤5 家）依《官网诊断AI采集_D2受控例外决策单_20261125.md》条款 1–8 执行；回应率读数出来或试点终止时自动失效。
- **本阶段不出现任何股权、合伙、服务费字样。**

### 阶段二（本计划新增）：创始付费批次

以「服务换案例与共建」为主，首批 3–5 家，由蔡工亲自交付。

```
免费入口：外贸数字门面机会扫描 / GEO 就绪度体检
    └─ 公开页只读 + 企业自填问卷 + 30 分钟初诊（企业同意后）
        └─ 一页机会卡（不称完整诊断报告，不给等级认证）
            └─ 报价（附带一句创始客户权益说明，不提股权）
                └─ 签约 50% / 验收 50%
                    └─ 交付（两条线，主线 + 例外）
                        └─ 案例授权（脱敏版；实名署名/参访＝加成）
                            └─ 案例入真相层 + 脱敏版可对外
```

**阶段一 → 阶段二的衔接**：阶段一的回应率读数是阶段二的前提读数，但不构成硬阻断——阶段二可由蔡工书面裁定提前启动（首批熟人公司路径），前提是阶段二开工前六项门槛齐备（§5.3），其中包含为交付期 AI 只读体检另出一份受控例外决策单。

## 3. 关键事实（2026-11-26 现测，引用前仍须现测）

### 3.1 股权型安排在现有体系里是空白

- 仓内 `docs/` 与 `server/` 检索「原始股／股权／股份／期权／干股／折股／持股／equity／shareholding／vesting／esop」：**零真正的股权设计**。命中的「持股」是《商业特许经营管理条例》对「直营店」的定义摘录，与本平台无关。
- 文档中心 BP v4.1（投资人版／精简版）**没有任何「客户付费换股权」「服务费折股」条目**。

### 3.2 BP 自身把「原始股」列为募资禁用话术

BP 投资人版 §9.4 第 3 条：「不得用「原始股」「内部额度」话术……不使用「原始股」「即将上市」「保本」等表述」；§10 将其列为募资合规事故风险。精简版 06／08 节同句。同节另规定：不得面向不特定多数人募集、不得代持、不得通过有限合伙把不特定多数人资金吸收进来。

→ 结论：「面向一批企业、统一规则、付费即送股」正是 BP 要防的形态。**对外任何材料不得出现「原始股」三字。**

### 3.3 经营主体

- 文档侧：公司全称、股东、注册地、发票主体在 BP、路演稿、签字确认单、品牌归档件中**全部标「待确认／待补」**；《首单上线风险清单》阶段 0 的「对公账户／个体户／个独三选一」未勾选。
- 本人答复（2026-11-26）：**已有有限公司**。→ 创始批次以该主体签约、收款、履约；主体信息与税务口径仍须补入合同与内部登记。

### 3.4 估值与折算基数

- BP 种子轮：融资 ¥3,000,000、投前估值 ¥10,000,000、新增股份 23.1%；创始团队（蔡工）65%–70% ＋ 4 年 vesting ＋ 1 年 cliff；期权池 10%–15%。
- 若未来恢复股权型权益，折算估值须**显式写死**（不是名额均分、不是池子事后按点数分），并设首批合计内部总上限；折算估值与总上限**属未决项**（§7），首批不落地。

### 3.5 客群实况推翻「首个标准件＝GEO 优化」的前提

2026-11-26 首页快扫 8 家（真相层《快扫发现清单-20261126.md》）：

- **8 家中 0 家拥有「存在且可正常访问」的独立官网**；1 家有站但证书过期＋CDN 域名失配（技术性死亡），5 家检索面确认无官网，1 家存续存疑，1 家主体待核。
- 由此头落地为三种形态：①建站/数字获客缺位（多数）②「贵司官网已死」③「只有平台店没有独立站」。

→ 因此首批保留两条交付线，但**不凑固定配额**：已有站走 GEO 优化主线，无站/死站才进建站例外。

### 3.6 工作台与网络现状

- **工作台内没有官网诊断或 GEO 审计模块**（检索命中的 `geo` 是派单地理分，`audit` 是 AI 调用审计）。GEO 交付靠本机技能完成，再以交付包形式登记进工作台。
- **本机直连不到海外 AI 搜索平台**：Google／ChatGPT／Perplexity 三探针全部超时；国内站点（百度、搜狗、抖音等）可达；`gsxt.gov.cn` 返回 521，工商信息改走 aiqicha／qcc／tianyancha 公开检索面。
- 本机两个 GEO 技能瞄准海外 AI 搜索且口径互相冲突：一个把 `llms.txt` 当交付物，另一个引 Google 官方指南称其无效、GEO 本质仍是 SEO 基本功；后者并写明「没用工具实测就不许给平台打分、不许承诺排名或引用提升」。**本计划采用后者口径（证据型、不承诺）。**
- pandoc 在位；Chrome 不在默认路径（PDF 报告生成路径需另设）。

## 4. 产品与价格

### 4.1 免费入口：外贸数字门面机会扫描 / GEO 就绪度体检

- 公开页只读 + 企业自填问卷 + 30 分钟初诊（须取得企业同意）。
- 产出「一页机会卡」：数字获客门面现状与可改进点。**不称完整诊断报告、不给等级认证、不估损失金额、不承诺分数带来订单。**
- **不索取**：网站后台权限、客户名单、联系方式、敏感经营数据。询盘入口只记「类型」与「位置」。
- 与「获客诊断工具」既有免费漏斗分层：本入口是**人工主导的一对一触达**场景，不占用企业主体的免费诊断额度（额度归属待首个正式企业账号接入时另定）。

### 4.2 收费产品两条线

| | **主线：GEO 优化** | **例外：最小外贸数字门面建设** |
|---|---|---|
| 适用 | 已有站（活着的） | 无站 / 官网已死 |
| 创始价（暂定） | **¥3,980** | **¥9,800 起** |
| 交付内容 | 可直接粘贴上线的成品件（改写文案、FAQ、结构化数据、robots 规则）＋给客户建站商的改进工单 | 固定模板中英双语站：固定页面结构、页面数上限、语言版本、资料清单、托管交接 |
| 明确不含 | — | 复杂询盘系统、电商、CRM、广告投放、持续代运营 |
| 上线责任 | 客户或其建站商发布；蔡工做上线前检查＋上线后复检 | 同左 |
| 超出边界 | 另议 | 另行报价，不进首批权益基数 |

- 两条线**共用**同一套创始批次合同与案例授权规则，权益基数按**实际收款**计算；交付物、周期、成本、验收分别列明，**不得用 GEO 优化的交付物替代建站交付物**。
- 价格为暂定占位（沿用体系内既有档位）。首批必须记录**真实工时、直接成本、毛利**，复盘后改正价。

### 4.3 效果承诺口径（证据型，不承诺）

GEO 优化只报告可测事实：AI 爬虫可读性（按 bot 分列，不合并）、渲染方式、内容可引用性、结构化数据、搜索面现状。**海外 AI 可见度标为「客户自测」或「未测」。不承诺排名、引用、询盘或收入提升。**

可见度测量方式（因本机直连不到海外平台）：附英文问句集，客户经自己合规的海外渠道提问并回传截图，蔡工整理成前后对照。

### 4.4 验收

按**交付物**验收：交付物清单齐全 ＋ 前后测量报告如实呈现即通过。不设效果型尾款条件。

## 5. 交易、交付与准入

### 5.1 合同包（三件套）

1. **有限公司服务合同**：交付内容、价格、付款、验收、保密、上线复检责任、案例授权勾选位。
2. **逐单 SOW**：本单范围、交付物清单、周期、验收标准、超出边界处理。
3. **单独案例授权**：脱敏版可对外、实名署名/接受同行参访（**加成项，非条件**）、禁止内容。

**合同里不写股权、不写合伙、不写份额。**

### 5.2 系统落地

- **交易侧**：合同由有限公司**线下签署**；工作台登记报价、合同指针 ＋ sha256、付款状态、授权回执。**不新建**电子合同、在线支付、退款、结算模块；**不启用**区域售卖流（该闸仍挂特许经营四项合规条件）；**不新建**股权相关数据模型或字段。
- **交付侧**：每家客户在系统内以**代号**建项目，交付包、任务、证据、封存、验收全程走系统。
- **真相层**：真实企业名与调研原件落仓外真相层目录，仓库与数据库只存代号 ＋ 指针 ＋ sha256。

### 5.3 第一笔真实付费服务的六项开工门槛（缺一不开工）

1. **创始批次书面裁定**：明确创始批次为有限公司直营服务单、合同不向任何人承诺分成、因此 DIFF-09 不构成其前置；签约与收费对创始批次一次性授权；交付期 AI 只读体检另出一份受控例外决策单（格式同试点决策单）；原始想法的股权层不进入首批。**（须业务与财务确认，AI 不代签。）**
2. 有限公司服务合同模板（含三件套三份文本）。
3. 两类产品的报价与验收 SOW。
4. 单独的案例授权条款。
5. 税务、开票与收款主体确认（主体已存在，但开票路径与税率口径须定）。
6. AI 只读采集与联网边界确认（阶段一决策单在读数出来后失效，交付期需新依据）。

### 5.4 客户准入清单（首批 3–5 家）

须**全部**满足，否则不占创始名额：

- 有明确决策人；
- 有真实外贸或跨境业务；
- 能提供品牌、产品、案例素材（决定建站可行性）；
- 能配合上线与复检；
- 接受证据型交付（不要求保证排名或订单）；
- 愿意授权脱敏案例，或至少允许形成内部案例。

### 5.5 权益兑现结构（两段）

| 触发 | 生效权益 |
|---|---|
| 交付验收通过 | 共建客户身份 ＋ 创始价锁定（40% 段） |
| 案例可对外使用（脱敏版） | 完整共建权益（60% 段） |

- 实名署名／接受同行参访＝**加成项**，不作条件。
- **转介绍不作条件**——一旦写入条件，案例授权即变成推广报酬，性质不同。
- 服务类权益（年度复检、优先排期等）**暂缓**，待律师审定的创始支持者方案确定后统一处理。

## 6. 指标、止损与不越界声明

### 6.1 四项经营闸门（首批结束后统一复盘）

1. 有效回应率；
2. 付费转化率；
3. 按时验收率；
4. 单家真实工时／直接成本／毛利。

**案例授权率只记录，不作为客户必须满足的条件。**

### 6.1bis 首批＝方法验证场（2026-11-28 评审拍板 E-4① 增补）

首批的定位从「案例＋收入」扩为「**案例＋收入＋可复制资产**」——每家客户除正常交付外，须沉淀可复用资产包（复盘件／交接件／可复用方法件，均取结项既产物指针），供换人复跑与第二批复用。复盘读数在四项经营闸门之外增两项：

5. 资产包被第二人实际取用次数（换人复跑或第二批引用）；
6. G9 后责任期内客户自运维达成率。

配套两条纪律：①首批如实告知客户这是首批探索（方法与资产沉淀含在其中），并保留其退出权；②每单复盘表预埋「本单是否智能体协同（agent_assisted）＋实际工时」两列——数据从第一天积累，提效读数（B3-2）等首批有真实协同/非协同对照包后再宣，**冻结的是宣读数、不冻结收数据**。

### 6.2 四类硬止损（任一触发即暂停新增签约，先复盘修正）

1. 连续两家无法按时完成；
2. 单家毛利为负；
3. 客户配合导致周期失控；
4. 出现合规、数据或权限风险。

### 6.3 首批之后与招商/融资的衔接

复盘通过后再扩张，**不自动进入招商或融资**；未通过则保留案例、修正产品。招商与融资仍是原路径（BP v4.1 种子轮与区域合作商体系），本计划只为其提供案例与单位经济性证据。

### 6.4 不越界声明（本计划不动的东西）

- 不改《官网诊断获客与上门访谈详细设计 v1.0》《标准业务体系设计方案 v1.0》的既有拍板口径；
- 不改 BP 的种子轮条款、合格投资者门槛、募资禁用话术；
- 不动 DIFF-09 的签署流程与五席落库口径（对外一律只引用有效交付 35%，不得引用 B8 披露的 40%）；
- 不开区域售卖闸、不动特许经营四项合规条件、不动实名股东／分公司／直营店形态认定；
- 不新建任何股权、分红、期权、持股数据模型或表；
- 不做「向不特定多数人募集」的任何形态。
