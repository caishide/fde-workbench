# GEO 优化与最小外贸数字门面：交付物清单 ＋ 可见度测量问句集 v1.0

**配套文件**：《FDE创始企业共建服务计划-v1.md》§4.2（两条交付线）、§4.3（证据型不承诺）、§4.4（按交付物验收）。

**用途**：这是首批 3–5 家的**交付物清单**（合同附件 SOW 的默认内容）与**可见度自测问句集**（客户在其合规海外渠道提问后回传截图）。两者共同保证：①每次交付的产物形状一致；②验收只看交付物与如实呈现的测量报告，不承诺任何提升幅度。

**红线重申**：客户自测结果是**客户自测**，报告中必须如此标注；不得由 AI 或交付方代答、不得替客户提交任何平台查询、不得使用未授权的第三方账号代测。

---

## 一、主线：GEO 优化标准件（GEO-01）

### 1.1 交付物清单（验收对象）

| 编号 | 交付物 | 形态 | 说明 |
|---|---|---|---|
| G-01 | 现状体检报告 | Markdown＋PDF | 分五块：①AI 爬虫可读性（按 bot 分列，训练类与检索类不合并）②渲染方式（服务端渲染/CSR）③内容可引用性（自包含答案块、问答式标题、事实与数字、数据新鲜度）④结构化数据（JSON-LD 现状与建议）⑤搜索面现状（收录量级、品牌词与产品词的可见位置） |
| G-02 | AI 可见度问句集 | Markdown | 见本文件 §三；中英对照，每条标注意图类型 |
| G-03 | 页面改写成品件 | Markdown，按页分文件 | 可直接粘贴上线：H1/H2 重写、自包含答案块、FAQ（含常见问法 8–12 条）、产品描述改写（英文优先）、事实与数据补强建议 |
| G-04 | 结构化数据成品件 | JSON-LD 片段 | 按页面类型给出（Organization／Product／FAQPage／BreadcrumbList／WebSite） |
| G-05 | robots.txt 与 AI 爬虫策略建议 | 文本＋diff 说明 | **按 bot 分列**给出允许/建议禁止的判断依据与理由（训练类与检索类分别给结论），**不代客户决定训练数据策略** |
| G-06 | 改进工单 | Markdown | 面向客户建站商或网站负责人的逐项施工清单（改什么、在哪改、验收怎么看） |
| G-07 | 上线前检查表 | Markdown | 客户发布前自查项（移动端、HTTPS、缓存、结构化数据部署校验、sitemap 提交） |
| G-08 | 上线后复检报告 | Markdown | 上线后重跑体检的对比结果；**只呈现差异与如实结论，不写提升幅度承诺** |
| G-09 | 英文问句集回执 | 截图归档 | 客户回传的自测截图，仅作**客户自测**记录 |

**不交付**：网站后台代管；广告投放；内容持续代写；AI 可见度的效果保证；排名或询盘预测。

### 1.2 验收口径（按交付物，不按效果）

通过条件＝G-01…G-08 齐全 ＋ G-09 客户是否回传不影响通过（记录即可）＋ G-08 如实呈现差异。
**不通过条件**：G-01…G-08 有缺项，或 G-08 出现与实际不符的表述。

### 1.3 交付记录（进工作台）

每家客户在系统内以代号建项目；交付包内容＝上述九项的指针与 sha256；任务、证据、验收记录全程进系统。

## 二、例外：最小外贸数字门面标准件（WEB-01）

### 2.1 产品边界（固定，不逐单谈）

| 项 | 固定值 |
|---|---|
| 语言 | 中文站 ＋ 英文站（英文站为必配，出口企业买家在海外） |
| 页面结构 | 首页 / 产品（分类页＋详情页）/ 关于我们 / 工厂与产能 / 联系与询盘 / 资质与认证 —— **6 个板块，不多不少** |
| 页面数 | 详情页 6–12 个（按客户实际产品线），**上限 15，超出另议** |
| 模板 | 固定模板（2 套配色可选），不做定制视觉设计 |
| 资料清单 | 客户提供（产品参数、工厂照片、资质证书、联系方式），**客户提供为交付前置** |
| 询盘 | 表单型（姓名、公司、国家、邮箱、需求描述）＋ 邮箱与 WhatsApp 入口；**不含**即时聊天、客服、CRM 对接、询盘自动分配 |
| 托管 | 客户自有服务器或指定托管方；交付**静态站 + 部署说明 + 域名与证书配置指引**；**不含**服务器采购、域名代购、续费代管 |
| 不含 | 电商与在线支付、复杂表单/多级询盘、CRM、广告投放、内容持续代运营、APP、小程序 |
| 语言版本 | 中英双站**内容对应**（不做多语言路由的复杂实现） |

### 2.2 交付物清单（验收对象）

| W-02 | 中英文文案成品 | Markdown，按页分文件（可直接粘贴） |
| W-03 | 静态站源码 | 目录（HTML/CSS/JS/图片占位） |
| W-04 | 结构化数据与 SEO 基础配置 | JSON-LD ＋ robots.txt ＋ sitemap.xml |

| W-06 | 上线前检查表 | Markdown（同 G-07） |
| W-07 | 上线后复检报告 | Markdown（同 G-08） |

|---|---|---|

## 三、可见度自测问句集（客户在合规海外渠道提问，回传截图）

**使用说明**（随 G-02/W-08 交付）：
1. 本问句集**每家一套**，按客户产品线替换方括号内容；
2. 客户在**自己合规的**海外渠道提问（自有海外账号、海外同事、分公司账号），把**带提问时间与渠道**的截图回传；
3. 回传结果在报告中一律标注「**客户自测**」，写明渠道与日期；**未回传也照常验收**（只影响案例丰富度，不影响交付验收）；
4. **AI 不得代客户提问，不得使用任何第三方账号代测**。

### 3.1 意图类型分类

| 类型 | 含义 | 用途 |
|---|---|---|
| T1 品类词 | 「哪类供应商」 | 看是否被列入候选 |
| T2 规格词 | 「带某参数的产品」 | 看产品匹配度 |
| T3 地域词 | 「某地/某国供应商」 | 看本地化可见性 |
| T4 认证词 | 「有某认证的工厂」 | 看资质可见性 |
| T5 品牌词 | 「某品牌」 | 看自有品牌心智 |

### 3.2 英文问句模板（每类 2 条，共 10 条）

| 编号 | 类型 | 问句 |
|---|---|---|
| Q1 | T1 | Who are reliable [product category] manufacturers in [country/region]? |
| Q2 | T1 | What [product category] suppliers should I shortlist for [application]? |
| Q3 | T2 | Which suppliers offer [product] with [specification]? |
| Q4 | T2 | Where can I source [product] meeting [specification]? |
| Q5 | T3 | Are there [product category] factories in [city/province] that export to [market]? |
| Q6 | T3 | Which [product category] manufacturers in [country/region] work with [market] customers? |
| Q7 | T4 | Which [product category] suppliers hold [certification]? |
| Q8 | T4 | Looking for [product category] OEM partners with [certification] — who are they? |
| Q9 | T5 | What is [Brand Name] and do they manufacture [product category]? |
| Q10 | T5 | Is [Brand Name] a reliable [product category] supplier for [market]? |

### 3.3 中文问句模板（供国内 AI 搜索与中文渠道自测）

| 编号 | 类型 | 问句 |
|---|---|---|
| Q11 | T1 | [产品类别]的靠谱供应商有哪些？ |
| Q12 | T1 | 做[应用领域]应该考察哪些[产品类别]供应商？ |
| Q13 | T2 | 哪些供应商提供[产品]并满足[规格]？ |
| Q14 | T3 | [城市/省份]有没有做[市场]的[产品类别]工厂？ |
| Q15 | T4 | 哪些[产品类别]供应商持有[认证]？ |
| Q16 | T5 | [品牌名]是做什么的？是[产品类别]厂商吗？ |

### 3.4 回传格式要求（给客户的一页说明）

- 每个问句 **1 张截图**，画面须含：完整问句、AI 回答、品牌是否出现及其位置；
- 记录：**渠道名称**（如某 AI 搜索／某聊天工具）、**提问时间**（精确到日）、**是否出现本企业**（是/否）、**出现位置**（第几条回答/被引用来源/仅提及名称）；
- 无需提供账号密码、Cookie 或任何凭证；**截图前请遮挡个人账号信息**；
- 回传渠道：由蔡工指定（线下交付时一并给）。

## 四、报告表述纪律（写在模板里，逐份执行）

1. 可见度数据一律标「**客户自测**」或「**未测**」，不得写成「实测」。
2. 不写「提升」「优化后排名上升」「询盘增长」等效果型结论。
3. AI 爬虫结论必须**按 bot 分列**（检索类与训练类分别给结论），不得合并成一句「AI 能不能看到你」。
4. `llms.txt` 相关建议必须写明：**对 Google 搜索无影响**；是否生成交客户决定，不作效果承诺。
5. 引用第三方数据（如市场规模、转化倍数）必须带来源与日期；无来源的数字一律不写。
6. 客户名称在对外版本中按 SOW 约定的代号处理；案例公开版本另按《案例授权》条款脱敏。
