## Q1 · 免费额度按法人还是按集团计

- **背景**：ADR-004 §1.4「多子公司保守默认＝不分别体验」——本期不建母子公司图谱，同 `subject_key` 即同主体；子公司持各自 USCC 在形式上是不同法人，各可领一份免费额度。**滥用敞口**：一个集团可经 N 家子公司领 N 份额度。现行遏制＝人工闸：额度授予/完成确认均走 admin＋密码确认（高风险写），交付咨询环节人工核验集团关系（ADR-007「AI 出建议、人判定」形态）。
- **请法务确认**：「不分别」是否合规默认？还是为防滥用/规避（尤其若与区域售卖 ADR-005 的「两店一年」主体资格判断相关）需要**集团层面归并计数**？
- **工程影响**：若 B（归并）＝额度主键需引入集团归一键（母公司 USCC 或集团码）——ADR-004 §3 已注明「法务确认后如口径变化（如需集团归并键），**改 `normalize_subject_key` 单点即可**」；若 A 被确认＝本单销号、人工闸保留、ADR 补记「法务已确认」。
- **等待方**：法务（X-03）；**到位后动作**：改 `normalize_subject_key` 单点＋去重用例（变异验证）＋ADR-004 状态回填。

## Q2 · 注册面是否携带「母公司 USCC」

- **背景**：ADR-004 §1.4 第二句——「法务口径到位后可在 G6 注册面加母公司 USCC 字段做结构化归并（本期不做，显式挂账）」。
- **请法务确认**：字段**必填还是选填**；填了是否须附**亲子关系证据指针**（见 Q5）；母子 USCC 与工商登记不一致时的校验规则。
- **工程影响**：注册面 payload ＋1 字段；是否需新表取决于 Q1 终态（归一键若落 `EnterpriseFreeQuota` 侧则零新表）。
- **到位后动作**：与 Q1 同一 PR 落地（口径成对）。

## Q3 · 无 USCC 主体（境外主体等）

- **背景**：ADR-004 §3——「校验位算法若法务口径要求放宽（如境外主体无 USCC），**另立裁决修订本 ADR**」。现状＝mod-31 硬闸（字符集 18 位＋校验位，失败 400 `invalid_subject_key`）。
- **请法务确认**：本期商用线是否**只覆盖境内 USCC 主体**（＝现状硬闸正确，零改动）；还是需放行非 USCC 主体（＝须先定义新键空间与校验规则，另立裁决，**不进本单实施**）。
- **到位后动作**：确认「只境内」＝零代码销号；需放宽＝另立 ADR-004 修订轮。

## Q4 · 额度去重规则终态（任务书 §17-3）

- **背景**：任务书 §17-3「企业主体认定口径（工商口径）确认 → 额度去重规则最终化」。现状去重＝`EnterpriseFreeQuota` 主键 `subject_key`（USCC 单键），grant 幂等「绝不新建第二份」。
- **请法务确认**：终态去重口径＝USCC 单键（现状）还是集团归一键（与 Q1 成对）。
- **到位后动作**：确认现状＝任务书 §17-3 销号、零代码；需变更＝与 Q1 同落点实施。

## Q5 · 集团归并主张的证据要求

- **请法务确认**：主张「A 子公司归并到 B 母集团」须何种证据——**工商集团关系页／年报等文件的 `source_uri`＋sha256 指针**（门禁证据红线同尺：只存指针＋指纹，原件留项目工作目录不进库），还是维持现状无证据、仅 admin 人工核验。
- **到位后动作**：证据制＝挂既有门禁证据登记面（零新表）；维持人工制＝零代码。
