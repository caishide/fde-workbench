拍板结论速览（已由 OWNER 签署，勿再讨论、勿擅自更改）：
- 隔离路线 = 甲：orgs 独立表（类型 enterprise/internal）+ projects.org_id 推导
  + 复用 project_members + 应用层统一入口；**不启用 RLS**；乙路线保留为规模化演进。
- org_id=NULL = 平台身份不受 org 限制（跨 org 可见须留痕）。
- 注册审核制 = 企业客户与创业者自助激活；交付者需审核（R 分层证据链）；区域服务商需审核。
- 计费 = 先免费额度；订阅结构随 M6 落，金额另拍；M5 的三付费选项是静态结构呈现。
- 容量 = 不改现服务器先试点；M0 须现测并发三项，实测前**不承诺任何并发数字**。
- W0 试用平台与商用平台**分离**；演示服务器在 M8 试点前零改动。
- 第一位试用客户过渡 = M1 完成后评估，**不预设迁移**。
- 交付者供给 = OWNER 亲自兼任首交付者；派单引擎只在本平台供给池内撮合；
  有真实外部交付者前不激活派单 / R 分层 / 席位计费。
