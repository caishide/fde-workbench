## 3. 步骤二：配置凭据（蔡工亲手，一次）

**为什么**：种子 agent 的 `credential_ref` 全指向 `default` 槽位，但 `default` 这一行**尚不存在** ⇒ `_unavailability` 会判 `credential_missing` ⇒ run 发起直接 409。

**两种方式**（等价，前者可复现）：

### 方式 A（推荐，走本轮新路由）

```bash
# 平台管理身份（org_id IS NULL 的 admin）＋ 账号密码
curl -X POST http://127.0.0.1:8010/api/v1/agents/credentials \
  -H "Authorization: Bearer <你的 access token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"default","credential":"<zcode provider 的凭据>"}'
```

**响应**只含 `{"id","name","credential_configured":true,"created_by_user_id","created_at"}`——**没有明文、没有密文**（明文只在这一次请求内存中出现，落库是 Fernet 密文）。

### 方式 B（本地脚本，既有唯一创建点）

```bash
cd server && .venv/Scripts/python.exe scripts/simulation/sandbox_real_e2e.py
```

**建议用 A**：B 只在本机活库生效，裸机不可复现。

**校验**：`GET /api/v1/agents/credentials` 应看到 `default` 且 `credential_configured: true`。

## 5. 步骤四：发起首个 run（蔡工亲手，H4 不可代）

**唯一人机路径**（桌面端无按钮）：

1. 在 AI 对话里让助手发起 run（助手走 `api_execute` → `agents.run_start`）；
2. 系统返回 **`awaiting_confirmation`**（15 分钟确认窗），弹出「确认 AI 敏感操作」框；
3. 在框里**输入当前账号密码**，点「验证并执行」；
4. ⇒ run 落库（`POST /api/v1/agents/{agent_id}/run`，body 只允许 `project_id` / `solution_id` / `idempotency_key` / `difficulty` 四个字段）。

**为什么必须这么绕**：N5/G-02 把 `agents.run_start` 列入 `CONFIRMATION_KEYS`（risk=3），AI 侧发起只能「提议」，**AI 不代发起 run** 是红线。

**直接调 HTTP 也行**（人直调不经二次确认，但仍需 AI 授权档位 ≥ agent 的 `capability_tier`）：

```bash
curl -X POST http://127.0.0.1:8010/api/v1/agents/<agent_id>/run \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"project_id":"<pilot-001 的 id>","idempotency_key":"pilot-001-run-01"}'
```

**闸位清单**（撞任一即失败，错误码见括号）：agent 不存在(404)／persona 不可执行(409)／项目不存在(404)／AI 授权档位不足(403)／**凭据缺失(409 `credential_missing`)**／agent 不可用(409)／T1 计划评审门未过(409)／T6 高成本评审门未过(409)／同幂等键上次失败须走 retry(409)／月预算超(409)／试点 run 超上限(409)／命中脱敏禁区词(422)。

## 6. 步骤五：只读采集（Agent 可代，系统侧只读）

run 落库后，Agent 侧只做**只读采集**（不造证据）：

```bash
psql "$FDE_DATABASE_URL" -f scripts/verify/verify-run-evidence.sql
```

输出四口径 + `[0/4]` 数据闸。**当前 `approval_rows=0`** ⇒ 仍 `NO_RUN_EVIDENCE` ⇒ **D7 阈值继续禁预支**。

## 7. D7 复审轮（等真实数据出齐后）

| 步骤 | 动作 |
