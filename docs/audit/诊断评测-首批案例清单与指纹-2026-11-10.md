## 三、污染隔离登记（R-4）

| 隔离位 | 规则 | 机械面 |
|---|---|---|
| 仓库 → 生成器 | `ground_truth` 键名（`problems_expected` / `solution_direction` / `result` / `human_boundary`）**永不进**生成器提示词、few-shot、知识库、检索索引 | T-06 静态钉（作用域：`server/tests/fixtures/diagnostic_eval/` + 提示词装配路径 + 知识库路径） |
| 真相层 → 仓库 | 本文件即仓库侧的唯一登记面；**内容层为零** | 审计清单检查 |
| 评测集版本 | 每张卡的 `card_version` 绑定；**改 `ground_truth` 必升版本并打曲线断点**（防「改考题刷分」） | T-09 版本标签 |
| 展示面例外 | 展示页（工具内示例报告 / 网站案例页）**可以**使用 ground truth 生成展示内容——但须带角标「示例案例 · 据公开案例整理」/「脱敏真实交付 · 代号化」，**不得呈现为实时诊断结果**，且展示产物目录**不得**被生成器检索路径引用 | 角标静态钉（T-10 起） |
| 反例隔离 | 元验证反例（注入 / 越权索证）是**攻击样本**，可入仓 fixtures，但**不得与答案键同目录**，避免被误当 few-shot | 目录隔离钉 |

## 五、卡片 sha256 的用途

sha256 有两个用途，**都不是内容**：

1. **防偷换答案**：评测运行时重算真相层文件的 sha256，与本表比对；不一致 ⇒ 该卡**不得**用于判定（否则等于改考题不记账）。
2. **指针化登记**：任务书、裁定单、评分表、曲线一律只引 `case_id` + sha256，**不复制答案内容**。
