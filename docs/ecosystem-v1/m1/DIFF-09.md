# DIFF-09 首单分账核对

业务和财务需在首单签约前统一合同、手册与 B8 的对外披露，确认计提基数及规则版本，并用同一笔批准的样单逐席核对合同、系统账单和应付款。对齐完成前，对外文件不得以 B8 的交付 40% 承诺分成。

## 桌面演算

本机活库只读复核显示 `dispatch_rule_versions` 仅有 v100 一行，状态为 `active`。以下以五席履职、计提基数 ¥55,000 为例，金额为预扣前分配额。

| 席位 | v100 有效比例 | 桌面演算金额 |
|---|---:|---:|
| 平台 | 30% | ¥16,500.00 |
| 拉单 | 21% | ¥11,550.00 |
| 交付 | 35% | ¥19,250.00 |
| 区县 | 7% | ¥3,850.00 |
| 省级 | 7% | ¥3,850.00 |
| 合计 | 100% | ¥55,000.00 |

B8 披露的交付 40% 在同一基数上折算为 ¥22,000，差额为 ¥2,750。实际样单以经确认的计提基数和规则快照为准。存在空缺席位时逐席登记原因与确认依据，平台承接核准的空缺份额及分币尾差。规则和金额计算见 [五席分账规则](../../commercialization/rules/five-seat-split-rules.md) 与 [结算服务](../../../server/src/fde_api/dispatch/settlements.py#L244)。

## 合成同单核对

同一合成项目的 ¥18,000 报价以 B 型合同台账登记，G4、G8 各回填 ¥9,000。每笔实收先生成四席草稿，交付份额为 ¥3,600。随后在草稿阶段显式调用五席分配服务，引用 active v100 快照，每笔分配如下。[同单结算续验](VALIDATION.md#同单结算续验)

| 席位 | 每笔分配 | 两笔合计 | 两笔合计扣除本场已计预扣 |
|---|---:|---:|---:|
| 平台 | ¥2,700.00 | ¥5,400.00 | ¥5,400.00 |
| 拉单 | ¥1,890.00 | ¥3,780.00 | ¥3,780.00 |
| 交付 | ¥3,150.00 | ¥6,300.00 | ¥6,298.80 |
| 区县 | ¥630.00 | ¥1,260.00 | ¥1,260.00 |
| 省级 | ¥630.00 | ¥1,260.00 | ¥1,260.00 |
| 合计 | ¥9,000.00 | ¥18,000.00 | ¥17,998.80 |

B8 的交付 40% 在每笔 ¥9,000 上为 ¥3,600，比 v100 分配多 ¥450。科目引用五席分配的税前金额，系统在 G8 里程碑结算行计入 ¥1.20 交付预扣。省级进项票用同笔结算及省级收款主体的科目登记。表中末列仅为本场按已计预扣复算的金额。

商机归因复跑用平台确认的归属人解析拉单席，G4、G8 每笔均为 ¥1,890，合计 ¥3,780。商机结算回执指向 G4 的拉单科目，G8 的拉单科目另挂同一派单包的 G8 结算。正式样单逐笔核对两个里程碑的科目、应付和付款。[同单商机归因](VALIDATION.md#同单商机归因)
