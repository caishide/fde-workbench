## 薄切片场次登记

首片为一个创业者、一个企业和一个交付者。试点运营确认候选组合与企业端手机网页可达性后，登记场次、使用环境、版本和各环节责任人。签约与收费使用对应授权，DIFF-09 需在首签前消解。

每片记录实际成交档位与到账、获客、质检、返工、差旅、兜底和回款时差成本，以及现金贡献、创始人工时和创业者获得首笔收入所用时间。首片成功后由另一组人用同一套材料复跑。失败场次登记阻塞环节、原因和下一片修正。真实凭证保留于授权的本地真相层，回执只登记 `source_uri` 与 SHA-256。
