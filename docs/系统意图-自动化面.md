# 系统意图：自动化面（AI 与外部自动化）

> 内嵌 AI、任务自动化与外部桥接的触发/工具面/输出契约/开关（goal-r3 G2，2026-10-30）。核心原则：**App 拥有副作用，AI 只产出建议**；写路径一律过确认流或人工拍板。

## 1. 内嵌智能助手（桌面右下角 + 微信入口）

| 维度 | 事实 | 代码 |
|---|---|---|
| 触发 | 用户对话（桌面）或微信消息；自动运行=否（每条消息级幂等：同 message_id+prompt 返回原 turn） | `control/chat.py:99-128` |
| 执行路径 | 优先 DSH runtime；未启用则**降级直连供应商 + 本地工具循环**（标 degraded） | `ai_server_client.py:135,203-247` |
| 工具面（14 个，MCP） | 只读 12 个全员/按 capability；写类仅 2 个：`api_execute`（走人工审核目录+密码确认流）、`file_send_wechat`（workbench.write） | `mcp_gateway.py:32-50` |
| 工具面收窄 | 降级模式只暴露 READ_ONLY_TOOLS 白名单（写工具不提供）；≤6 轮、单结果 24k 截断 | `ai_tool_loop.py:32-55` |
| 鉴权 | 每次 MCP 调用实时验证 15min JWT + AI 级别 ∩ capability | `mcp_gateway.py:53-104` |
| 引导（steering） | `_workbench_system_prompt`：先 help_fetch 查手册再作答、不代拍板、claimed≠accepted | `chat.py:50-71` |
| 硬护栏（非 prompt） | 工具白名单本身、capability 鉴权、api_catalog 只收人工审核过的原子操作、敏感操作密码确认、微信密码指令不进模型 | `api_catalog.py:14-74` |
| 输出契约 | turn 状态机 queued→running→completed/failed；失败原因落库可见 | `chat.py:133-195` |
| 开关/限流 | AI 级别 disabled=403；月度 token 预算 FDE_AI_MONTHLY_TOKEN_BUDGET 超额拒 | `chat.py:76`、`auditing.py:52` |
| 知识 | help_fetch 读内置手册（16k 窗口/分页/章节定位），手册文本是资料不执行 | `help_bundle.py:41-67` |

## 2. 预调研 AI 分析管道（流 1 的自动化段）

| 维度 | 事实 | 代码 |
|---|---|---|
| 触发 | 人工点「开始分析」→ HTTP 入队 `project.presurvey.analyze`；**无自动定时触发** | `guidance/service.py:67` |
| 工具面 | Kimi 文件客户端只读源文件流（≤10MB、scan clean 门前置在选源步） | `guidance/jobs.py:52-60` |
| 输出契约 | `validate_guidance_output`：字段集精确匹配 + source_ref 白名单 + 条目四键；不符 → 自动重试 1 次后 `failed/ai_output_invalid` | `guidance/ai_schema.py`、`jobs.py:78,96-110` |
| 副作用归属 | AI 只写草稿（draft）；confirmed 只能人工（`confirm_analysis` can_manage） | `guidance/service.py:173` |
| 失败处理 | failure_code 落库、前端轮询可见（2s，失败提示不清空状态） | `PresurveyAnalysisAction.tsx:14-20` |
| 开关 | FDE_KIMI_* 配置；DB system_configuration 可覆盖模型/key（加密入库） | `model_preferences.py` |
