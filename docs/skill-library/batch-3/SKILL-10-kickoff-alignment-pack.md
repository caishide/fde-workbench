# SKILL-10 启动会对齐材料包

项目启动会是一次把「做什么、不做什么、谁拍板、何时算成」当面说清并落笔的开局对齐。本技能指挥 AI 在会前备齐材料草稿、会中按固定顺序推进、会后产出纪要与决议登记草稿；所有落笔经蔡工确认。

## 适用场景

- 合同签订或立项批准后的首次客户正式会议之前；
- 范围曾口头扩张、需要当面钉边界的项目；
- 客户方换人（新分管领导、新对接人）后的重新对齐会。
不适用：门禁与技术评审会（走门禁评审纪律）；客户侧决策链还没摸清时，先出干系人决策地图再定参会人。

## 怎么做

1. 会前几天用项目查询工具汇集：合同范围条款、既有决议、里程碑与关键节点、在途风险、待澄清清单；缺的材料在草稿里立「待会中补齐」占位，不臆造。
2. 产出三份草稿（文档生成，均标「草稿·待蔡工审定」）：①会议材料包——背景一页、范围边界对照、里程碑与关键节点、沟通机制草案；②议程——顺序固定：背景对齐 → 范围边界 → 里程碑 → 角色与拍板机制 → 风险与预案 → 共识确认；时长按会议规模与参会人定，不设固定分钟表；③开场核对单——材料是否发齐、有拍板权的人是否到场、演示环境是否就绪。
3. 会中纪律：范围外请求当场记入「待澄清」，不现场承诺；每条决议当场复述一遍请对方确认；角色记到「谁对什么签字」粒度，细粒度决策链交给干系人决策地图技能。
4. 会后：纪要草稿＝决议、待澄清、行动项三张清单；行动项必带负责人与触发时点；逐条对照会议原话，不改写客户表述。决议与待澄清经蔡工逐条确认后写入项目备忘；初始风险不在此展开，占位后转交付风险登记册技能建账。
5. 完成判定：三张清单确认落笔、每个未决项都有主且有触发点；缺任一项输出 blocked，并列出缺什么、找谁补。

## 人机边界

- AI 只汇集、起草、复述、登记；决议永远由人当场拍板；
- 备忘写入与对外发送逐次经蔡工确认；客户原话不改写；
- 会议记录的结构化抽取是产品既有能力面，本技能只产出草稿文本，不替代、不绕过该面；
- 会上演示只用授权环境，不展示未授权数据。
