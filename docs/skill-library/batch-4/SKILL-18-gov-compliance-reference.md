# SKILL-18 G 端合规速查（交付侧合规地形指北）

参考型技能：政务、国企、事业单位类项目从接触到验收，G 端特有的一组合规地形要提前认得。本卡回答「该域管什么、权威文件在哪、FDE 交付时注意什么」——它是找文件的指北，不是合规结论；**每处引用都以官方标准原文为准**。

## 适用场景

- G 端项目接触、方案、交付、验收任一阶段，需要快速对齐合规地形时；
- 客户提出等保、信创、数据安全等要求，需要知道权威在哪、该读什么文件时。
不适用：以合规建设本身为交付物的安全集成项目（须按官方标准与测评机构要求做完整方案）；具体政策补贴测算（走产品测算卡规则面，无金额无分数纪律）。

## 使用纪律

- 本卡是「权威在哪里」的指北，不是合规结论：任何一格都不能当成满足要求的证据，引用一律回到官方原文与合同条款；
- **零金额零分数**：本卡不载任何补贴金额、评分与比例；项目数字一律回官方原文与合同；
- 落笔日 2026-11-12；法规与标准会更新，引用前以现行官方原文为准；
- 合规判断归客户合规口与法务，本卡帮 FDE 问对问题、找对文件；
- 涉密与未公开要求不进本卡、不进任何会话记录。

## 人机边界

- AI 只做指路与草稿；合规判断与对外承诺永远由人并经客户合规口确认；
- 引用官方原文必须逐字核对原文本身——拿不到原文就写「待查原文」，不凭记忆引；
- 与产品测算卡规则面分工：政策补贴测算走测算卡，本卡管交付侧合规地形。
