# SKILL-17 行业速查（FDE 垂直行业参考）

参考型技能：进入一个不熟的行业客户前，先查这张表拿「方向感」——该行业痛在哪、第一脚踩哪、最容易砸哪、红线在哪。本卡是进门地图，不是行业权威。

## 适用场景

- 接触新客户、需要快速了解其行业交付地形时；
- 方案或报价前判断「这行业的特殊约束会打到哪个环节」时。
不适用：替代行业精读（真做一个行业，回真相层对应专题精读）；替代任何行业法规与标准原文。

## 跨行业共性（先走这五条，再谈行业差异）

1. 到现场跟岗共情，是各行业通用的入场第一脚；
2. AI 只出建议，拍板权始终留在人手里；
3. 幻觉靠「溯源＋独立核验」双闸兜住；
4. 数据不求先治干净：先在现有数据上跑通，边跑边治；
5. 延迟、隐私、离线三类约束会把推理推向端侧。

## 使用纪律

- 本卡每格都只是方向感（orientation），深做某行业必须回真相层对应专题精读；客户现场的一手观察永远压过本卡；
- **零业务数字**：本卡不含任何业务数字；外部书稿与调查里的行业数字一律视为编译口径，引用前逐项打折标注，不得写成「我们做过」；
- 行业差异不是跳过基本盘的借口：跨行业共性五条照旧先走。

## 人机边界

- AI 只在会话中按需引述本卡做方向参考，引述时说明「参考卡口径」；
- 对外材料引用任何行业结论，先经蔡工确认；
- 本卡不替代行业法规、标准与客户内部制度的原文。
