# SKILL-20 客户沟通速查（七个沟通场景的方向判据）

参考型技能：与客户、同事、上级谈事情时，这张表给的是「先判断什么、判据落在哪、别踩什么坑」的方向，不给话术、不给分级表、不给升级时限。它帮人在开口前想清楚该先处理哪一层，不代替人开口。

## 适用场景

- 客户提了变更、异议或情绪，需要判断先接哪一头；
- 要向上汇报或向多方同步，事先定结构；
- 承诺与实际出现落差，需要决定怎么讲、什么时候讲。
不适用：需要成套话术与场景对照表（那些属结构化表达，不搬入本仓）；需要对外承诺、报价、收款（走本仓报价与收付面）；需要正式会议纪要抽取（走纪要抽取面）。

## 速查表（七个沟通场景）

| 沟通场景 | 先判断什么 | 判据落在哪 | 最容易踩的坑 | 与本仓既有面的分界 |
|---|---|---|---|---|
| 变更与承诺 | 客户要的东西现在接不接得住 | 先量化影响再谈接不接；规模决定这件事谁拍板；口头承诺要落成书面；批准之后基线跟着变；客户往往不止一个可行选项，别只给一种 | 没评估就答应，把伤害留在后面 | 需求变更单归交付方案生成面 |
| 异议与分歧 | 对方说的是信息缺口还是态度对抗 | 先让对方讲完；澄清比认同更能推进；回应要有证据；价格异议换算到对方的账上算；异议记下来往往就是需求入口 | 急着反驳，或用一堆形容词代替证据 | 提问清单归售前诊断框架 |
| 情绪与信任 | 情绪有没有被接住 | 没被接住时谈不下去；道歉针对造成的影响而不是针对人；承诺要小而确定；情绪强度不同要用不同节奏并留痕；信任靠后续兑现恢复 | 把情绪当噪声跳过，事后追认没接住 | 客户模拟归训练场 |
| 现场汇报 | 听众要记住什么 | 目标是让人记住结论而不是听完；结构先定再包装表达；结论越早给，信任建立越快；形容词不可信，可比较的数字才有说服力；每个论点挂得住证据；结尾要落到明确的行动请求 | 按时间顺序讲流水账 | 汇报材料生成归交付方案生成面 |
| 跨方协同 | 谁决定、谁关心 | 决策权与影响力分开看；沟通频次与形式提前约定；升级路径事先说清；冲突调解先分开听再找共同目标；结论落书面各方确认；角色立场不同是常态 | 把「大家都同意了」当成达成一致 | 干系人地图归干系人决策地图 |
| 预期与兑现 | 落差来自执行还是来自当初的口头放大 | 承诺留余量；偏差在还能补救时讲，越晚讲越贵；主动同步是信任来源；每阶段重新对齐一次成功标准；兑现承诺之外的小事是超出预期的来源 | 只在客户问起时才同步 | 范围与验收口径归交付方案生成面 |
| 高层汇报 | 高层要拍什么、要信什么 | 高层时间最稀缺，信息密度决定成败；先结论、再证据、最后请求；数字要能追到来源；不同职位关注面不同，要换语言；备询材料是防追问的保险；汇报之后要有跟进动作 | 铺垫太长，结论藏在最后 | 高层沟通练习归本仓沟通演练面 |

## 跨场景共性（先走这四条，再谈单场景）

1. 结论先行：任何一场都要先说结论或先提请求，铺垫越靠后，听众越容易走神。
2. 承诺要小而确定：宁可给一个小而准的承诺，也不要给一个大而虚的承诺。
3. 证据优先于形容词：能比较的数字与可核的动作，胜过所有修饰。
4. 落成书面：口头共识不算共识，跨方尤其要把结论写下来并各方确认。

## 使用纪律

- 零业务数字：本卡不含任何时限、阈值、比例与金额；升级路径与节奏以客户现场判断为准。
- 本卡是方向判据不是话术库：来源的场景话术、分级表、步骤序列、时刻表一律未搬，含等价复现；真要开口时按现场语境自己组织表达。
- 借鉴层边界：只取「先判断什么」的思考顺序与关注点，不取表达方式本身。
- 落笔日 2026-11-12；来源仓库停更已超复核窗口，本卡按当日重核通过的快照写成，引用前复核来源现状。
- 客户现场的一手观察优先于本卡；本卡与现场冲突时以现场为准，并回头修订本卡。

## 人机边界

- AI 只按需引述本卡、指出该先判断哪一头，不代替人开口、不代替人判断对方情绪；
- 对外承诺、道歉、让步、报价与承诺时间，一律由人拍板；
- 客户与上级的真实意图只有人能读出来；读不出就问，不要用本卡猜。
