## 三、独立重写声明与防抄口径

1. **独立重写**：3 份全部为本仓原创文本。SKILL-19／SKILL-20 的写作工序＝子代理先出思想级笔记（约定零长片段改述、数字只登记不采信），本卡再二次改写成表；SKILL-21 直接按「判据维度＋检查顺序」重写。来源的字段槽位组、步骤序列、参数表、阈值项、门禁检查组、结论状态词表、模板资产与示例数据文件一律未搬，含改数字、换措辞、重排的等价复现。
2. **零业务数字纪律（参考型附加，本批三份统一）**：SKILL-19 全卡零业务数字（外部材料里的数字视为编译口径，引用前逐项打折标注，不得写成「我方做过」）；SKILL-20 零时限零阈值零比例；SKILL-21 零性能数值、零容量数字、零超时秒数与门槛值，样例阈值不可当客户已认可的标准。
3. **形态纪律（参考型附加）**：三份均不指挥工具动作循环，不含命令、参数、模板与产物格式；只给方向与判据。
4. **防抄四连（本批实测口径）**：15 字滑窗（归一化剥空白与反引号）对 16 个源文件全扫；英文 ≥15 字符片段抽查；禁词零命中（评测集真相层目录名＋两仓真名，字面不写入交付面）；参考型附加扫描（五节结构齐备＋零业务数字纪律）。
5. **标识符豁免口径**：命中若为对照表声明的标识符子串（来源路径 `skills/deployment/...`、来源文件名如 `性能调优技`／`异议应答框` 等）计为已声明豁免，其余命中即失败。
