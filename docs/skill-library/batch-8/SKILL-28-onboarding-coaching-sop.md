# SKILL-28 · 新人带教与 SOP 沉淀（育才）

> 用途：把新人养成从「跟着看」变成可考核的爬坡，把老师傅的做法沉淀成新人能独立执行的 SOP。团队扩张期与交付沉淀期用。

## 适用场景

- 新人进项目，需要一段有通关标准、不靠自觉的带教期；
- 项目里反复出现同类操作，每次质量因人而异，需要固化成标准作业程序；
- 老人要撤场（见 SKILL-05），带教与 SOP 是「能力留下」的两条腿。

不适用：一次性、不会再做的任务——写 SOP 的成本高于收益；涉及客户机密且无法代号化的流程——按机密口径另行管理，不入通用 SOP 库。

## 怎么做

1. **三段爬坡定带教**：新人成长按三段推进——**听懂**（知道这件事为什么这么做）、**跟着做**（在带教人在场时做完一次完整流程）、**独立做**（不带教独立完成并经受一次真实检验）；每段晋升以考核通关为准，不按到点即升；
2. **每段三元绑定**：每个阶段配齐三样——学什么（内容）、做什么（实操任务）、怎么算过（可考核的通关标准）；三样缺任何一样，该阶段不算成立，考核无从谈起；
3. **SOP 化先看触发**：一件工作值不值得写 SOP，先过三条触发判据——重复做（还会再来）、容易错（历史上有翻车）、质量波动大（不同人做结果差得多）；三条全占优先写，只占其一先记进待办不占编制；
4. **SOP 五面骨架**：一份能用的 SOP 覆盖五个信息面——**它是什么与边界**（解决什么、不管什么）、**谁来做与前置条件**、**怎么做**（步骤动词开头、每步输入输出明确）、**做砸了怎么办**（常见错误与现场补救）、**附什么件**（模板、样例、核对表）；写完不给老人看，直接给一个新人试读；
5. **新人试读定稿**：SOP 的质量终极判据是「新人只看文档就能独立执行」——请未参与过的新人按文档走一遍，凡是需要回头问作者的位置就是文档缺口，改到走通为止；之后每次现场纠错回写 SOP，文档跟着活；
6. **反馈回路**：带教与 SOP 各设固定复盘节奏（节奏多密由团队自定），复盘只问三件事——爬坡卡在哪一段、SOP 哪一步被反复问、通关标准是不是形同虚设。

## 人机边界

AI 可以做：起草带教计划与各段三元绑定表初稿；起草 SOP 五面骨架初稿与步骤拆解；生成通关考核题与核对表；核对新人文档走查记录里的「回头问」位置并归类；按复盘三问整理材料。

人必须做：爬坡段位与通关的判定；实操带教本身；SOP 的行业口径与客户边界审核；复盘结论与计划调整的拍板。

红线：AI 不得代判「新人已通关」；SOP 发布前必须经人审核（客户信息代号化核查）；带教记录与考核结论由人签字。
