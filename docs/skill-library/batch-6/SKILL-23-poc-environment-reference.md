# SKILL-23 POC 环境与验证速查（六个进场判断的方向判据）

参考型技能：客户要开一个限时验证（POC）时，这张卡给的是进场前与跑动中的方向判断——这次验证要证明什么、环境按什么档备、数据敢不敢用、验到什么程度算过、结论怎么写、收完东西去哪。它不指挥工具动作循环，不给配置清单、按天的节奏划分与阈值组合，只给方向判据。

## 适用场景

- POC 开跑前，要把环境、数据、验证口径一次定清楚；
- 跑动中要判断环境算不算就位、数据能不能用、验到哪算过；
- 收口时要写一份不被客户觉得白跑的结论报告。
不适用：POC 结束后的复盘与学习回写（归 POC 收尾复盘卡）；运行期的现场排障与技术判据（归技术交付速查）；长期交付形态与生产验收证据链（归部署形态速查）；性能压测的口径与分层定位（归技术交付速查，具体场景走客户环境实测）。

## 速查表（六个进场判断）

| 进场判断 | 判断摊开看哪几头 | 判据落在哪 | 最容易踩的坑 | 与本仓既有面的分界 |
|---|---|---|---|---|
| 这次要证明什么 | 验证目标写成可判定的成功口径（哪几个场景走通算数）；要验什么与明确不验什么当场划开；客户侧参与人与到场方式约定好 | 成功口径动手前双方认可；没有成功口径的验证跑完必然各说各话 | 把「演示一下」当验证目标，结论无处落脚 | 售前阶段的提问与诊断归售前诊断框架 |
| 环境按什么档备 | 从验证目标反推环境档位，不照生产规格搬——算力与运行形态、存储与数据通道、访问入口、观测手段四头够用即可；环境与生产隔离、可弃、可重建 | 就位的标志是每个部件能被一条健康判断证实，不是「装完了」；重建路径事先走通一遍 | 照生产规格砍半搭环境，结论与真实场景对不上；环境不可重建，中途坏了全场停摆 | 长期交付形态的证据链归部署形态速查 |
| 数据敢不敢用 | 可用性三问——脱敏在前（客户真实数据不进验证环境，合同明确允许除外）、覆盖在中（样例要盖住要验的场景，不只拿最顺的一撮）、量级在后（规模失真会让性能结论失效） | 数据不就位不进场；脱敏规则归本仓脱敏管线面，本卡不自造 | 拿客户生产数据直接灌进验证环境；或用极少的样例宣告「验证通过」 | 客户数据脱敏规则归本仓脱敏管线面 |
| 验到什么程度算过 | 功能按场景逐一走通（异常路径也走，不只跑顺的）；性能先测底再改、改完同口径复测；稳定连续跑一段再看，不拿瞬时表现当结论 | 每条用例的预期结果执行前写死；「通过」的定义双方事先对齐；没验到的如实记「未验证」 | 边跑边改预期结果；把最好一次的成绩当成能力 | 口径与分层定位的系统判据归技术交付速查 |
| 结论怎么写不白跑 | 结论与限制同段呈现（验到什么、没验到什么一起交）；证据留痕（过程可回看、结论可复核）；已知问题与遗留清单单独成节；下一步建议给方向不给承诺 | 报告里每句结论能追到一条证据；「未验证清单」必须存在 | 只报好的一面，客户追问没验的部分当场塌台 | 报告文档本体与对外承诺归交付方案生成面 |
| 收完东西去哪 | 临时产物处置事先约定（哪些留、哪些清、谁保管）；学到的东西走复盘回写；要不要转正式交付是独立决策，不因验证跑通自动成立 | 环境与数据按约定处置，不留「先放着」的悬置态；转交付走各自的立项与合同动作 | 验证环境转正使用，绕过正式交付的全部证据链 | 复盘与学习回写归 POC 收尾复盘卡；转交付决策归商务与合同面 |

## 进场前先过四条

1. 环境是验证工具不是缩小版生产：按验证目标反推，够用、可弃、可重建。
2. 预期结果先于动手：没写死预期的用例不进执行。
3. 数据不就位不进场：脱敏、覆盖、量级三问过不了就停。
4. 结论与未验证清单一起交付：只报一半的结论不是结论。

## 使用纪律

- 零业务数字：本卡不含任何天数、时长、并发数、规格数字、容量与性能数值；环境档位、验证节奏与时长以客户现场实测与约定为准。
- 本卡是方向判据不是操作手册：来源的部件配置清单、按天划分的节奏表、性能阈值组合、验证用例与报告分段模板一律未搬，含改数字、换措辞、重排的等价复现。
- 与既有卡的分工：POC 开跑前的准备与跑动中判断归本卡；收尾复盘与学习回写归 POC 收尾复盘卡；运行期排障归技术交付速查；长期形态与生产验收归部署形态速查。
- 落笔日 2026-11-12；来源仓库停更已超复核窗口，本卡按当日重核通过的快照写成，引用前复核来源现状。
- 客户现场的一手观察优先于本卡；冲突时以现场为准，并回头修订本卡。

## 人机边界

- AI 只按需引述本卡、帮人把进场判断摊开成文，不代替人确认环境就位与验证结论；
- 环境动用客户侧资源、数据进出客户环境、对外发布验证结论，一律由人拍板并走客户授权；
- 「算不算通过」由人对照事先写死的口径判定；AI 不代下「验证通过」的结论。
