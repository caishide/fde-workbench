## 批 B（r2 AI 链计量与红线，先投）

### QR-024 直连腿流式 usage 恒采集失败（P1）
- **锚点**：`server/src/fde_api/ai/deepseek.py:507`（`35ffbea` 时点）。
- **事实**：流式路径 usage 三重机理恒采集失败——后台主路径计量恒零，AI 预算闸系统性失效。
- **修复方向**：usage chunk 解析修复；采集不到时诚实置 None（不得静默记 0 冒充免费）＋流式计量测试钉——预算闸在流式路径须真实计量。
- **验收**：变异红→绿（usage 丢失时计量/闸行为可判别）；流式与非流式计量对齐钉。

### QR-025 预调研 DOCX 原件脱敏前上传供应商（P1，复核注可升 P0——随批裁定）
- **锚点**：`server/src/fde_api/ai/kimi.py:74`。
- **事实**：E4/A2 外发红线被时序架构违反——DOCX 原件未过 T-A2 脱敏即上传供应商 API。
- **修复方向**：上传前预检（未脱敏原件禁止出站）或废弃上传腿改本地解析；旧正例测试钉若断言「上传在先」须随修复换代并留痕。
- **验收**：变异红→绿（原件出站路径被钉死）；P0 升级注记随批回写台账。

### QR-117 富文本键名契约断裂（P1，趋 P0——随批裁定）
- **锚点**：`rich_text.py:163-167`＋`DocumentEditor.tsx:196-198`（`35ffbea` 时点）。
- **事实**：桌面保存 `text` 键 vs 服务端读 `content` 键——编辑器正文逐块静默丢弃、保存即抹、不进 DOCX（自 v0.1.0）。
- **修复方向**：服务端兼容 `text` 键（存量数据可救）＋双端键名闭集契约钉；存量已丢数据的迁移/恢复注记如实登记（救不回的明说）。
- **验收**：变异红→绿（`text` 键正文丢弃→修复后保留）；契约钉换代。

### QR-118 complete_upload IntegrityError 未映射（P1）
- **锚点**：`server/src/fde_api/files/service.py:857`。
- **事实**：同名上传 500／重试恒 422／abort 400——会话永久卡死（rename 面已有 409 同文件语义，不对称）。
- **修复方向**：IntegrityError→409 对齐 rename 面＋replay 兜底。
- **验收**：变异红→绿（同名 complete 上传 409 而非 500/永久卡死）；409 语义钉。
