## 三票收敛项（本轮最重发现）

**逐 PR 验收判定**（防作弊官＋纪律官＋老调度独立撞出同一洞）：v1 的 §9-2/§7 用「基点..fork/main」区间 diff 判「零本线生产 diff」，在本仓日均 10+ PR 并发、插队十四度有先例的现实下**判定式自身必假红**，且漏 `scripts/` 禁改路径、无法归因他线改动。v2 修法＝弃区间口径，逐 PR `merge-base..head` 断言 changed-files ⊆ §4 白名单闭集（显式含 scripts/、server/tests、desktop/tests 三条禁改路径），收口汇十张清单为全链证据。
