## 三、缺口（有意图规则、零验证，按暴露排序）

| 缺口 | 风险 |
|---|---|
| `FDE_MODEL_CREDENTIAL_KEY` 派生关系无测试（轮换 JWT secret 后已存密文可解性未钉） | 密钥轮换事故面 |
| 桥快照推送的**重放**（同 bundle 二次 POST）行为未钉 | 投影重复/审计噪声 |
| 微信入口（weixin_message_handler）密码指令不进模型——只有代码注释，无测试 | 提示注入面 |
| 桌面 `allowsRendererUrl` 打包态 file: URL 判定无单测（集成在 index.ts 内） | 主进程信任边界 |
