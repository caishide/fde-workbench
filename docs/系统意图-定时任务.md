# 系统意图：定时与后台任务

> 容器侧后台 + 宿主侧计划任务的运维地图（goal-r3 G2，2026-10-30）。改 `server/` 后必须 `docker compose build && up -d`（代码烤进镜像）。

## 容器侧（compose.yaml）

| 服务 | 入口 | 判活 | 语义 |
|---|---|---|---|
| worker | `flask worker`（compose.yaml:81；循环见 cli.py:139-170） | Redis 心跳键 `fde:health:worker` TTL 180s（heartbeat.py:30） | 消费 Redis list `fde-jobs`（FIFO）；单活租约 5min `(job_type,target_id)` 守卫（jobs/queue.py:51）；终态重放 no-op |
| scheduler | `flask scheduler`（compose.yaml:108；cli.py:172-188，默认 30s 轮） | 心跳 `fde:health:scheduler` TTL 900s（heartbeat.py:31） | 每轮 `dispatch_due_automations()`：扫 `automation_tasks` 到期行 |
| api | gunicorn（端口仅绑 127.0.0.1:8010） | `/api/v1/health/ready` 真校验 DB+Redis | — |

**scheduler 唯一周期任务**（无 beat 表）：`dispatch_due_automations`（`control/scheduler.py:62-94`）——`SELECT … FOR UPDATE SKIP_LOCKED` 取到期行 → 每条插入 `automation_task_runs`（幂等键 `schedule:{task_id}:{scheduled_for}` 唯一约束去重，models.py:133）→ `enqueue_outbox("automation.execute")` → 推进 next_run_at。schedule_kind：once / interval(`Nm/Nh/Nd`) / calendar(5 段 cron，逐分钟前推 ≤2 年) / event(不调度)（scheduler.py:17-59）。**无预调研类自动定时**——指引分析全由 HTTP 触发入队。

**worker job 类型**（`jobs/handlers.py:39-54`）：file.scan / file.preview / document.generate / project.presurvey.analyze / research.export / automation.execute / ai.chat / ai.execute。事件先落 `outbox_events` 再入队（outbox 模式，cli.py:159-163）。

## 宿主侧：FDE-Bridge-Poll（Windows 计划任务）

| 项 | 事实 | 出处 |
|---|---|---|
| 周期 | 每 4 小时（2026-10-25 用户裁决，原 15min）；StartWhenAvailable 错过补跑，限时 10min | `scripts/install-bridge-poll-task.ps1:11-16` |
| 动作 | `wscript //B` 隐藏跑 `run-bridge-poll.vbs` → `node bridge-poll.mjs >> logs\bridge-poll.log`（>1MB 自轮转） | vbs:13-26 |
| 采集 | openfde 只读 CLI 白名单 + fdeops 文件探针 → `POST /api/v1/bridge/snapshots`（Bearer FDE_BRIDGE_TOKEN） | bridge-poll.mjs:98-135 |
| 手动触发 | `schtasks //Run //TN "FDE-Bridge-Poll"`（Git Bash 双斜杠）或桌面「立即采集」（同一命令，`desktop/src/main/bridge-capture.ts:42`） | — |
| `--check` | 快照含 orphan 项目指针 → 退出码 2（§1 铁律巡检）；常规失败 1 | bridge-poll.mjs:18-20 |

**纪律**：采集器只读（绝不写真相层）；只能跑在 Windows 宿主（openfde CLI 是 Win 版 Node 工具，容器内 subprocess 不到）。

## 独立进程（不在 compose 内）

`python -m fde_api.control.weixin_worker`：微信收发循环，inbox-before-cursor 防丢消息（weixin_worker.py:1-8）。另有宿主采集器 runbook 技能 `.agents/skills/fde-bridge-capture/`。

**无其他定时面**：n8n 桥接（`QFhunterFeed01` 等）属 somwyn 管道侧，在仓库外，本仓库零代码耦合（grep 全仓仅历史文档提及）。
