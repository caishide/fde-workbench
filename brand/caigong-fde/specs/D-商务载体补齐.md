### 核心内容

**D5-1 建议规格（建议值 · 待确认②⑥）**

| 载体 | 建议尺寸 | 版式 |
|---|---|---|
| 工牌（竖版） | 54 × 86 mm（CR80 等效）+ 3 mm 出血 | 上 1/3：纯图形标居中 + 品牌全称；中：姓名（最大字重）+ 职位；下：细金线 + slogan 全句 |
| 桌牌（横版折叠） | 待确认② | 正面：纯图形标 + 姓名；背面可留白或放 G1–G9 轨道线（B5 ②） |
| 胸牌（展会） | 待确认② | 与工牌同版，缩小字阶 |

**D5-2 视觉规则**

- 优先**纯图形标** + 品牌名，不使用完整组合（含字标）——工牌幅面小，组合易低于 §六 的 120px 等效最小宽。
- 单色优先：浅底用 `mono-dark`（石墨黑），深底用 `mono-light`（纯白）；**工牌不出现金色**，避免小面积烫金工艺失真（若确需金，须待确认⑤后单列工艺稿）。
- 图形四周留白 ≥ 图形高度 1/4（§六）；图形不得拉伸、不得改开口方向。
- 姓名为视觉第一层级；品牌名为第二层级；slogan 最小，不得放大抢主体。
- 数字（工号/日期）用 B4 等宽数字；空字段写「—」。
- 所有文字字段在模板中以 `[[待确认]]` 占位，**不含任何虚构姓名或联系方式**。

**D5-3 与 D3 的一致性**：工牌、名片、邮件签名（C7）、PPT 封底（C8）中的品牌全称与联系方式必须来自同一份待确认信息表；任一处更新，四处同步（F3 巡检项）。

### 核心内容

> **⚠️ 合规前置声明（不可删）**
> 本节**只定义视觉边界与版式位置**，不构成印章刻制、使用或电子签名的授权，也不提供可直接套用的印章图样。
> 电子签章的法律效力来自签约主体资质、CA 证书与平台用印流程，与视觉规范无关；任何印章图样必须以**实际备案章样**为准。
> **禁止**由设计侧自行绘制、临摹、描边或「美化」公章用于对外文件；**禁止**把品牌主标当作印章使用。
> **2026-11-07 品牌侧朱红豁免裁决不改变本声明**：豁免仅解除「不得引入第三种彩色」这一条品牌用色纪律在签章区的适用，不产生任何用印授权。

**D6-1 版式位置（A 类 · 已定稿）**

| 项 | 规范 |
|---|---|
| 位置 | 签署页右下方，距右边距 ≥ 20mm、距页脚 ≥ 15mm；不压正文、不压页码 |
| 签章区建议尺寸 | 40 × 40 mm 方形预留区（**建议值 · 待确认**：以实际备案章样外径与平台签章组件为准，本文不定章面尺寸） |
| 周围留白 | 签章区外扩 ≥ 10mm 不放任何文字/图形/金线 |
| 与品牌元素的关系 | 签章区**不得**叠加主标、纯图形标、B5 母题或 slogan；品牌元素只在页眉/页脚出现（D4 已落地） |
| 签署栏 | 甲方/乙方、签署日期、授权代表为独立文字栏，不并入印章图形内 |
| 页面底色 | 保持 contract.docx 的纯文字保守版式，不加深底、不加金色块 |
| 单色处理 | 若必须黑白输出，按 `BRAND-COLOR-SPEC.md §七-5` 只保留石墨黑轮廓，**不得**把朱红替换为金色 |

**D6-2 朱红与「不得引入第三种彩色」的冲突（B 类 · 品牌侧已裁决 2026-11-07）**

- 品牌纪律：`BRAND-COLOR-SPEC.md §七-3` 不得引入第三种彩色，金色为唯一暖色。
- 电子公章实务：朱红为法定 / 功能性视觉特征，**不属品牌装饰色**。
- **裁决（依据用户 2026-11-07「14 和 D6 分级拍板按你建议实施」）**：允许作为 §七-3 的**唯一显式、有条件豁免**，书面条款已写入 `BRAND-COLOR-SPEC.md §七-3`。豁免边界：
  1. **仅限**签署页签章区；
  2. **仅限**实际备案章样（设计侧不得自绘、临摹、描边或美化）；
  3. **不扩散**至官网、名片、PPT、邮件签名、展会物料等任何其他载体；
  4. **不得**作为品牌色推广，不写入色板与任何 token；
  5. **不构成用印授权**，法律效力仍以主体资质、CA 证书与平台用印流程为准。
- **仍待输入**：法务对该豁免的**书面确认**；主体资质、备案章样、平台用印审批见 D6-4 C 类。
- ⚠️ 本节**不指定具体朱红色值**——章色以实际备案章样为准，设计侧不自定、不臆造。

**D6-3 落地流程（待触发，前置项见 D6-4 C 类）**

```
法务/主体资质确认（C 类①③）
  → 取得备案章样 / 平台签章组件（C 类②）
  → 法务书面确认 §七-3 朱红豁免（B 类，品牌侧已裁决）
  → 在 contract.docx 签署页验证位置与留白（不改页眉页脚；C 类⑤如需骑缝一并验证）
  → 走真实平台用印测试，验签通过（C 类③）
  → 写入 F2 CHANGELOG，纳入 F3 巡检（只巡检位置，不巡检章样）
```
